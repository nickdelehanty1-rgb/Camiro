# Data Processing Agreement — OpenAI API Services
## Excerpt for Compliance Review

**Parties:**
- Controller: AcmeHire Ltd, a company registered in Ireland
- Processor: OpenAI, L.L.C., a Delaware limited liability company

**Effective Date:** January 2024

---

## 1. Subject Matter

OpenAI will process personal data submitted by the Controller via the OpenAI API
on behalf of the Controller, solely to provide the API services.

## 2. Nature and Purpose of Processing

Processing of text data submitted through the OpenAI API, including generation of
AI model responses. The purpose is to provide AI-powered text generation and
analysis services to the Controller.

## 3. Duration

For the term of the API service agreement between the parties.

## 4. Types of Personal Data Processed

Any personal data included in API requests submitted by the Controller, which may
include names, CV text, cover letter content, and other applicant information.

## 5. Categories of Data Subjects

As determined by the Controller. May include job applicants and employees.

## 6. Processor Obligations

OpenAI shall:

- Process personal data only on documented instructions from the Controller
- Ensure that persons authorised to process personal data are bound by confidentiality
- Implement appropriate technical and organisational security measures per Art. 32 GDPR
- Assist the Controller in responding to data subject rights requests
- Delete or return personal data at the end of the service, at Controller's choice
- Make available information necessary to demonstrate compliance

## 7. Sub-processors

OpenAI may engage sub-processors to provide elements of the services.
OpenAI will notify the Controller of any intended changes to sub-processors.
A current list of OpenAI sub-processors is available at openai.com/policies/subprocessors.

The Controller hereby grants general authorisation for OpenAI to engage
sub-processors subject to notification obligations.

## 8. Controller Rights

The Controller may audit OpenAI's compliance with this Agreement, subject to
reasonable notice and OpenAI's standard audit procedures.
